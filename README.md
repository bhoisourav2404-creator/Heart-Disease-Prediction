# Heart-Disease-Prediction
I have created AI model using old medical data to predict the future heart disease.
Responsibilities:
•	Explored algorithms like Logistic Regression, Naïve Bayes, K-Nearest Neighbors (KNN), Decision tree.
•	Collected dataset and load dataset from UCI machine learning Repository
•	Split dataset for training and testing
•	Find the accuracy and result comparison of all algorithms
•	Integrated graphical representation of all algorithms for heart disease prediction
